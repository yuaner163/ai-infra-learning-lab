## 🚨 当前优先复习

### `pwd`

> [!warning] 当前重点
> `pwd` = **Print Working Directory**  
> 作用：输出当前工作目录的路径。  
> 最短记忆：**我现在在哪？**

Day 1 状态：

- 历史情况：多次出现理解/表述不够稳定
- 精确次数：从 Day 2 起开始累计
- 当前状态：🔴 高频薄弱点
- 下次学习开始前：必须先做快速复习题

常见错误表达：

- “显示当前路径明细”

更准确：

- “输出当前工作目录的路径”

### `~`

> [!warning]
> `~` 只代表当前用户家目录。

当前用户：

```text
~ = /home/yuaner
```

不是：

```text
/home/yuaner/下载
```

只有：

```text
~/下载 = /home/yuaner/下载
```

Day 1 状态：

- 已出现明确答错
- 当前状态：🟡 易错点

### `tail`

正确：

> 从文件末尾取 N 行，但结果内部顺序不会倒过来。

错误理解：

> “由后到前显示”

例如：

```text
Line 4
Line 5
```

不会显示成：

```text
Line 5
Line 4
```

Day 1 状态：

- 已出现概念混淆
- 当前状态：🟡 易错点

---

### 重定向 `>` / `>>`

核心：

```text
>  = 覆盖
>> = 追加
```

Day 1 真实错误：

```bash
echo ""Linux Day 1">notes.txt"
```

导致 `>notes.txt` 被当成普通输出的一部分。

正确：

```bash
echo "Linux Day 1" > notes.txt
```

规则：

> 重定向符放在引号外面。

当前状态：🟡 易错点

---

### `rm` / `rmdir` / `rm -r`

```text
rm      = 删除文件
rmdir   = 删除空目录
rm -r   = 递归删除目录及其内容
```

Day 1 曾出现：

```bash
rm backup/
```

以及：

```bash
rmdir backup/
```

对应报错帮助理解了文件和目录删除的区别。

当前状态：🟡 需要继续巩固
