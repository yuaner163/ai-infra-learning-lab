# 云运维 / DevOps 12周学习总纲

> 目标：先建立可就业的 Linux / 云运维 / DevOps 基础，再继续向 SRE、Platform Engineering、AI Infra 深入。

## 进度标记规则

- [x] ==黄色高亮==：已经完成，并经过实际操作或测试
- [ ] 普通未勾选：尚未完成
- 🔴 高频薄弱点：同一知识点反复提问 / 答错 / 混淆
- 🟡 易错点：出现过 1～2 次明显问题
- 🟢 稳定掌握：连续多次测试正确

> 以后每次学完，都会同步更新本文件和 `高频薄弱点.md`。

---

## 1. 总体目标

完成 12 周后，至少具备以下能力：

- 能独立使用 Linux 完成日常文件、用户、权限、进程、服务、磁盘、网络操作。
- 能进行基础 Linux 故障排查。
- 能写基础 Shell 脚本完成自动化任务。
- 能使用 Docker 构建、运行、查看和排查容器。
- 能理解并使用 Kubernetes 的核心对象。
- 能完成基础 K8s 故障排查。
- 能使用 Prometheus / Grafana 做基础监控。
- 能理解并搭建基础 CI/CD 流程。
- 能完成一个可写进简历的云原生综合项目。
- 能开始投递 Linux 运维、云运维、实施运维、技术支持、初级 DevOps、K8s 运维等岗位。

### 第 3 周：网络 + Shell

#### 网络

学习：

- IP
- 子网掩码
- CIDR
- 默认网关
- DNS
- TCP / UDP
- 端口
- HTTP / HTTPS
- NAT
- 路由

命令：

```bash
ip addr
ip route
ss
ping
curl
wget
dig
nslookup
traceroute
```

排障顺序：

1. 网卡是否存在？
2. IP 是否正确？
3. 默认路由是否存在？
4. DNS 是否正常？
5. 端口是否监听？
6. 服务是否返回数据？

#### Shell

学习：

- 变量
- 环境变量
- 参数
- 引号
- 条件判断
- 循环
- 函数
- 返回值

目标：

- [ ] 写一个基础系统检查脚本
- [ ] 自动检查 CPU、内存、磁盘、端口和服务

## 3. 每周测试机制

每周结束生成：

```text
WeekXX-周测.md
WeekXX-错误与遗忘总结.md
```

周测包括：

- 基础概念
- 命令判断
- 看输出判断结果
- 找错误
- 故障排查
- 终端实操
- 综合场景题

每周总结只保留：

- ⚠️ 真实错误
- 🧠 遗忘点
- 🔀 混淆点
- ❓ 理解不牢
- 🚨 高频薄弱点
- 🔁 下周优先复习

---

## 4. 薄弱点升级规则

以后精确累计四类次数：

- 提问次数
- 答错次数
- 混淆次数
- 遗忘次数

升级规则：

- 出现 1 次：普通记录
- 出现 2 次：🟡 易错点
- 出现 3 次及以上：🔴 高频薄弱点
- 连续 3 次测试答对：🟢 稳定掌握
- 后续再次答错：重新升级
