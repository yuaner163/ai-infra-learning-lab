# AI Infrastructure Learning Lab

A hands-on learning journey from Linux operations to Cloud Native and AI Infrastructure.

This repository documents my process of building practical infrastructure skills through learning, experiments, troubleshooting, and engineering practice.

## About This Project

This project is a long-term journey from fundamental Linux operations to modern AI Infrastructure.

The goal is not only to learn technologies, but also to develop real engineering abilities:

- Understanding systems
- Troubleshooting problems
- Automating repetitive tasks
- Building reliable infrastructure
- Learning how modern AI systems are deployed and operated

Learning path:

```text

  ↓

  ↓

  ↓

  ↓
AI Infrastructure
```

# Troubleshooting Philosophy

Infrastructure engineering is not only about remembering commands.

The core ability is solving unknown problems.

My troubleshooting process:

```text
Problem
  ↓
Observe
  ↓
Collect evidence
  ↓
Create hypothesis
  ↓
Test hypothesis
  ↓
Find root cause
  ↓
Document solution
```
