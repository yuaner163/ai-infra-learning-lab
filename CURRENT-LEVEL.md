## Linux Command Understanding


### pwd

Confusion Count:

Multiple times


Correct Understanding:

pwd = print working directory


Purpose:

Display the current working directory path.


Example:

Command:

pwd


Output example:

/home/user/project


Meaning:

The terminal is currently located in this directory.


Memory:

pwd = Where am I now?


---

## Path Concepts

Status:

Needs reinforcement


Common Confusion:

- Absolute path
- Relative path
- Current directory
- Home directory


Correct Understanding:

Absolute path:

Starts from the root directory.


Example:

/home/yuaner/cloud-learning


Relative path:

Based on the current location.


Example:

./project


Memory:

Absolute path = Full address

Relative path = Current location based address
